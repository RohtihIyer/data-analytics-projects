# Data Analytics Portfolio

Welcome to my portfolio! Here are the data analysis and visualization projects I have built using Python.

## 📌 Projects

* **01. iPhone Sales Analysis** – Analyzed iPhone sales trends, pricing, and buyer ratings.
* **02. IPL Data Analysis** – Analyzed match statistics and player performances in the Indian Premier League.
* **03. Netflix Content Analysis** – Examined movie vs. TV show distributions and release trends on Netflix.
* **04. Employee Career Survey Analysis** – Evaluated workplace feedback and career satisfaction metrics.
* **05. Customer Analysis** – Analyzed customer purchasing behavior and revenue performance.

## 🛠️ Python libraries
* NumPy, Pandas, Matplotlib, Seaborn, and Plotly.
